# 지식 저장소 등록 확인

기준일: 2026-11-11 / 상태: 등록·색인·검색 확인 완료

## 1. 등록 범위

| 저장소 | 등록 내용 | 확인 결과 |
| --- | --- | --- |
| WeKnora의 무역 지식베이스 | 원본 PDF 5개, 페이지별 본문·OCR 보충 5개, 학습노트·페이지색인·안내 3개: 총 13개 | 13개 모두 색인 완료, 새 교재와 학습노트 검색 확인 |
| TencentDB Agent Memory의 MemoryHub 무역 Wiki | 본문·OCR 보충·학습노트·색인·안내 8개, 자동 생성 검색 페이지 포함 총 450개 | ready 상태, 환리스크 검색 결과 확인, 비공개 설정 |

위 서비스는 개인 PC에 설치한 로컬 시스템이다. GitHub는 정리한 글의 버전 보관에 사용한다. 로컬 시스템을 외부에서 접속할 수 있게 공개한 것은 아니다. 시스템 주소·내부 ID·인증정보는 이 글에 포함하지 않는다.

## 2. 내용 확인

1. WeKnora에 올린 PDF 5개를 다시 내려받아 원본과 SHA256이 모두 일치함을 확인했다.
2. MemoryHub 본문 8개를 업로드한 텍스트와 대조했고, 자동 처리 뒤에도 본문 해시가 유지됨을 확인했다. 서비스가 추가한 잠금 표시는 대조에서 제외했다.
3. WeKnora에서 환리스크·매칭·선물환을 검색하여 신규 교재와 통합 학습노트의 청크가 반환되는 것을 확인했다.
4. MemoryHub에서 환리스크 관련 검색 결과를 확인했다.

## 3. 확인 범위와 한계

자료 저장·색인·검색을 확인했으며 모델 가중치를 추가 학습한 것은 아니다. MemoryHub가 자동 생성한 주제별 요약 전체는 별도로 검수하지 않았다. 해당 요약의 설명과 교재 본문이 다르면 원문과 검토 근거를 다시 확인한다.

현재 법규·세율·신고기한·금융상품·플랫폼 조건은 이번 등록에서 재검증하지 않았다. 조회·파일 등록을 실제 거래의 발주·송금·통관 완료로 사용하지 않는다.
