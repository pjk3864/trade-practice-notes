이 노트는 교육자료에 대한 독해와 내부 적용안이다. 법률·세율·기한·인증·보험 인수요건·은행 상품·플랫폼 운영현황을 2026년 기준으로 검증한 문서가 아니다. 자료에 2018~2020년 사례와 그보다 오래된 요율이 포함되어 있다. 실제 거래에서는 해당 시점의 공식 근거와 계약·은행·운송인 요구를 먼저 확인한다.

## 2. 전체 업무의 연결 구조

1. 품목과 역할을 정한다. 직접 매매하는 본인, 수수료를 받는 대리인, 자기 책임으로 수입·재판매하는 유통업자를 구별한다. 실제 계약·대금·물류의 당사자를 따로 그린다. (S-03 16~26, 207~211쪽)
2. 제품 경쟁력·공급능력·자금능력과 목표 시장의 수요·경쟁·유통·규제를 조사한다. 시장 규모와 특정 바이어의 구매의사는 별개로 확인한다. (S-03 27~34, 53~96쪽)
3. 바이어를 발굴하고 회사 실체·권한·신용·취급 경험을 확인한다. 문의 접수, 견적 요청, 샘플 검토, 주문 확정 단계를 구분한다. (S-03 117~192쪽, S-05 3~8쪽)
4. 규격·수량·단위·가격·통화·인도조건·결제·선적·검사·포장·보험·변경·클레임 조건을 문서로 맞춘다. (S-01 27~97, 182~189쪽)
5. 원가와 결제 시점별 자금·환노출을 확인한다. 판매가격과 원가, 원가 가산율과 매출 이익률을 구분한다. (S-03 99~116쪽, S-02 5~19, 156~173쪽)
6. 생산·검수·예약·반입·통관·보험·선적을 관리하고 서류 초안을 대조한다. 예약 완료, 신고수리, 실제 적재·출항, 최종 인도는 서로 다른 사건이다. (S-01 99~180쪽)
7. 대금 회수·지급·환전·비용을 증빙으로 정산하고, 클레임·미수·미지급·후속 영업을 추적한다. (S-01 23~24쪽, S-03 212~218쪽, S-05 17~21쪽)

## 3. 핵심무역실무에서 익힌 내용

### 3.1 용어·문서·계약

- 무역업고유번호, 통관 관련 식별정보, HS 품목번호는 용도가 다르다. 제품명만 보고 HS·세율·요건을 확정하지 않고 재질·용도·구조·제조공정 등 분류 근거를 확보한다. (S-01 4~16, 153~155쪽)
- P/I는 조건 제시·견적, P/O는 구매주문, C/I는 실제 거래의 물품명세·청구에 쓰인다. 문서 제목만으로 계약 성립이나 효력을 판정하지 않고 제안·승낙·변경과 실제 행위의 기록을 함께 검토한다. (S-01 29~37, 182~200쪽)
- 발주 시 계약·P/O·P/I의 버전을 연결한다. 다른 조건으로 회신한 문서를 기존 조건에 대한 단순 승낙으로 처리하지 않는다.
- B/L, AWB, 보험서류, 원산지증빙은 각각 작성·발급주체와 기능이 다르다. 파일 수취와 내용 검토, 은행의 서류 수리, 세관의 신고수리도 구분한다.

### 3.2 인도조건·수량·납기

- 인코텀즈는 운송·보험·통관 의무, 비용 배분, 인도·위험 이전, 제공서류를 검토하는 틀로 읽는다. 결제나 소유권, 계약위반 구제까지 자동으로 정한 것으로 사용하지 않는다. 적용 규칙·버전·지정장소를 계약에 명시한다. (S-01 40~60쪽)
- 특히 C조건에서 운임을 지급하는 목적지와 위험 이전 지점을 혼동하지 않는다. FOB/CIF의 본선 적재 개념과 FCA/CPT/CIP의 운송인 인도 개념을 구별하여 운송방식과 실제 인도 장소에 맞춰 확인한다.
- CIF/CIP 보험은 가입 주체만 보지 않고 담보약관·보험금액·통화·피보험자·배서·청구지·면책·구간을 확인한다. 교재의 구약관·신약관 명칭을 같은 계약조건으로 자동 치환하지 않는다. (S-01 121~134쪽)
- TEU·FEU·CBM·중량을 구별한다. 컨테이너의 교재상 적재 가능 부피는 참고치이며 실제 포장치수·중량·장비 제원·적입계획으로 확인한다.
- 선적일, 도착예정일, 인도일은 구분하고, 납기의 기산점이 계약일·입금일·신용장 접수일 중 무엇인지 적는다. 신용장 수량 허용오차를 모든 물품·모든 계약에 일률 적용하지 않는다. (S-01 45~49쪽)

### 3.4 운송·보험·통관·원산지

- FCL/CY와 LCL/CFS, 선사와 포워더, Master/House B/L의 관계를 이해하되 일대일 고정 공식으로 사용하지 않는다. 실제 계약운송인·발행인과 화물 인도 경로를 확인한다. (S-01 99~110쪽)
- 예약번호와 B/L 번호를 구분한다. 화물·서류 마감, 반입장소, 빈 컨테이너 상태, 적입·봉인번호, B/L 초안·원본 또는 인도방식을 점검한다. (S-01 105~115쪽)
- 운임은 본운임과 THC·CFS·문서비·유류·통화·성수기 할증 등으로 나눠 포함범위와 단위를 확인한다. 선급·후급 표기만으로 모든 출발·도착 비용의 부담자를 확정하지 않는다. (S-01 116~119쪽)
- 적하보험은 화물손해, 수출보험은 대금회수 등 각 상품의 담보대상을 중심으로 구별한다. 보험금액과 실제 지급 보험금도 다르다. (S-01 121~134쪽, S-03 91~97쪽)
- 통관은 품목분류·수출입요건·신고·검사·수리·납세·반출 및 사후관리로 연결한다. 과세가격은 송장금액을 무조건 그대로 쓰지 않고 가산·공제와 과세환율을 확인한다. (S-01 137~155쪽)
- 관세환급은 수입 원재료의 납세·소요량·수출사실 연결, 개별환급·간이정액환급의 구분을 학습했다. 교재의 신청기한·기업요건·환급률은 현행값으로 사용하지 않는다. (S-01 157~166쪽)
- FTA는 협정 존재, 해당 품목 양허, 원산지결정기준 충족, 운송요건, 증빙·신청요건을 함께 검토한다. 원산지국·선적국·송장발행국을 구별하고 제3국 경유·제3국 송장은 협정별로 확인한다. C/O 보유만으로 특혜가 확정되었다고 표시하지 않는다. (S-01 167~180쪽)

### 3.5 서식 대조

C/I는 당사자·품명·수량·단가·금액·통화·인도조건을, P/L은 포장별 수량·포장 수·순중량·총중량·부피·화인을, 운송서류는 운송인·송하인·수하인·통지처·장소·선적정보·인도방식을 대조한다. B/L 원본·배서·상환, AWB의 기능을 같은 방식으로 취급하지 않는다. 환어음은 발행인·지급인·수취인·금액·만기·기산일·인수·배서를 나눠 읽는다. (S-01 190~232쪽)

## 4. 환리스크 관리에서 익힌 내용

### 4.1 먼저 노출을 측정한다

- 환산위험은 보고통화 환산, 거래위험은 계약부터 결제까지의 환율 변화, 영업위험은 판매량·경쟁력·가격·원가 변화로 구분한다. 장부에 외화가 없다고 영업위험도 없다고 보지 않는다. (S-02 5~19쪽)
- 같은 환율 상승도 외화 순수취와 순지급에 반대 영향을 준다. 원/외화 1단위 기준에서 외화 수취자는 환율 하락, 지급자는 환율 상승에 취약한 구조로 점검한다.
- 거래ID·통화·금액·예정 수취/지급일·확정 여부·기존 헤지를 연결해 통화별·만기별 순노출을 파악한다. 다른 통화나 다른 만기의 유입·유출은 자동 상계하지 않는다. (S-02 156~173쪽)
- 목적은 영업 현금흐름의 불확실성을 줄이는 것이다. 환율 전망에 맞춰 추가 위험을 취하는 행위와 헤지를 구별한다. (S-02 8~11, 105~106쪽)

### 4.2 환율 읽기와 산출

- 통화쌍의 기준통화·상대통화와 표시단위를 먼저 쓴다. 은행의 매입률은 은행이 기준통화를 사는 가격이고 매도율은 파는 가격이다. 수입 송금·수출 수취에 맞는 환율 종류를 확인한다. (S-02 26~32, 53~75쪽)
- 매매기준율, 송금 환율, 현찰 환율, 실제 체결환율, 통관 과세환율, 회계 적용환율을 섞지 않는다. 100엔 고시처럼 100단위 값은 원/1엔으로 변환한 근거를 남긴다.
- 크로스 환율은 통화 단위를 약분해 곱·나눗셈 방향을 검증한다. 교재의 JPY/KRW 예시는 USD/KRW ÷ USD/JPY이며 bid/offer 방향도 교차 확인한다. (S-02 68~75쪽)
- 선물환은 현물환과 스왑포인트를 연결해 이해한다. 금리차 간편식은 교육용 근사치이며 미래 현물환율 예측이나 실제 거래견적이 아니다. 부호·pip 단위·일수·휴일·만기와 수수료를 확인한다. (S-02 77~103쪽)

### 4.3 수단별 구조와 운영 부담

| 수단 | 배운 구조 | 함께 확인할 부담 |

근거: S-02 104~154쪽. 표는 구조 이해용이며 상품 선택·가입 권유가 아니다. 실제 거래대금이 취소·지연되면 기존 헤지도 재검토한다. 실물거래의 이익과 헤지의 손실 또는 그 반대가 생길 수 있어 합산 현금흐름을 본다.

내부 수단은 동일 통화·만기의 매칭, 채권채무 네팅, 결제시기 조정, 통화 분산을 학습했다. 다만 실제 상계·기한 변경은 상대방 합의·신고 등 적용요건을 확인해야 하며, 환율 전망만으로 지급을 임의 지연하지 않는다. (S-02 164~173쪽)

### 4.4 거시지표·차트의 위치

금본위·브레튼우즈·변동환율·유럽통화제도·원화와 위안화 제도 변화를 배경으로 읽었다. GDP·물가·고용·수지·금리·심리지표는 시장 예상·수정치·정책 반응과 함께 봐야 한다. 교재의 ‘호조 → 달러강세’ 표를 고정 인과법칙으로 사용하지 않는다. (S-02 175~210쪽)

봉차트, 지지·저항, 이동평균 교차, MACD, RSI는 가격 움직임을 설명하는 학습 항목으로 정리했다. 차트 신호를 거래대금 환전·헤지의 자동 실행 근거로 사용하지 않는다. (S-02 212~230쪽)

## 5. 수출마케팅에서 익힌 내용

### 5.1 준비·조사·채널

- 자사 분석은 제품 차별성·생산·품질관리·자금·수출대응 조직을 묶는다. 영문 회사·제품자료, 검증 가능한 실적·시험자료, MOQ·리드타임·A/S 설명을 준비한다. (S-03 27~34, 223~241쪽)
- 시장조사는 목표국·수요·소비자·경쟁자·제품·유통·가격·촉진을 나누고, HS·기간·통화·수량단위·통계 출처를 기록한다. 시장 통계와 실제 바이어 면담을 함께 쓴다. (S-03 53~89쪽)
- 신용조사는 홈페이지·회사정보·연락처 확인에 더해 사업 지속성·지배구조 변동·취급경험·지급능력·조사일을 본다. 플랫폼 인증·좋은 응대·큰 주문 제안만으로 신용을 확정하지 않는다. (S-03 91~97, 174, 200~201쪽)
- B2B는 기업·제품정보와 검색 키워드를 준비하고 문의를 적격화하는 채널이다. 교재에 소개된 KITA·KOTRA·EC21·Alibaba·Kompass 등의 현재 서비스·이용료는 별도 확인 대상이다. (S-03 117~135쪽)
- B2C는 판매국·플랫폼·수수료·물류·반품·표시·인증·통관·광고를 함께 계산한다. 노출 부족, 클릭률 부족, 구매전환 부족을 나누어 개선한다. 상품 수 확대나 반품 완화는 교재의 조언이며 자동 방침이 아니다. (S-03 136~158쪽)

### 5.2 원가·물류 산출

수출가격은 제조·구매비, 포장·검사, 내륙·국제운송, 보험, 통관·서류, 금융·수수료, 기타 실제 부담비용을 확인한 후 검토한다. Incoterms별로 비용을 더할 때 이미 포함된 운임·보험·포장을 중복하지 않는다. (S-03 99~116쪽)

산출표에는 원통화·단가·단위·수량·기간·산출식·환율일·포함범위·견적 유효기간을 함께 둔다. 항공 용적중량의 제수, 적용중량·반올림, 해상 W/M 환산·최저요금은 실제 운송견적으로 확인한다. 교재의 6,000·167·1CBM 최저치를 모든 서비스에 고정 적용하지 않는다.

원가 100에 10%를 더해 가격 110으로 제시하면 원가 가산율은 10%, 매출 대비 이익률은 10/110이다. 교재 S-03 115쪽의 10%와 9.09% 차이를 이 구분으로 이해한다. 실제 회계상 이익은 환차·세금·기타 비용의 처리까지 별도로 대조한다.

### 5.3 전시회·영업 후속

- 전시회는 정보 수집·목표 설정·사전 준비·현장 운영·사후 평가로 나눈다. 실제 구매권한을 가진 참관객, 업종 적합성, 총비용, 경쟁사 참가 등을 확인한다. (S-03 162~177쪽)
- 사전에 바이어 약속, 샘플·카탈로그, 부스·시설, 운송·임시통관·재반출, 담당·예산·비상연락을 준비한다. ATA Carnet 등은 행사·국가·물품별 적용 여부를 확인한다.
- 현장 상담카드는 회사·담당·취급품목·구매권한·수요·상담내용·약속·후속 담당·기한을 남긴다. 교재의 A~D 등급은 근거 없이 배정하지 않는다. (S-03 249쪽)
- 교재는 감사 연락 1주 이내, 문의 답변 24시간 이내를 제안한다. 회사의 확정 SLA로 임의 채택하지 않고 실제 가능한 회신기한을 정한다. 즉답이 어렵다면 접수와 답변 예정시각을 우선 알린다. (S-03 177, 184쪽)

### 5.4 협상·계약

질문으로 용도·규격·구매량·판매채널을 좁히고, 근거가 있는 품질·납기·사후관리 가치를 설명한다. 할인·MOQ 완화·납기 단축은 수량·포장·사양·지급시기 등 상대 조건과 연결하여 변경 원가를 검토한다. 샘플의 품목·수량·가격·운임부담·평가목적을 먼저 맞춘다. (S-03 180~206쪽, S-05 3~14쪽)

독점은 지역·품목·채널·기간·최소실적·기존 고객·직접판매·지식재산 사용·종료·재고처리를 명확히 합의한다. ‘1년’, ‘보증 10~15%’는 교육 사례이며 자동 표준이 아니다. Agent와 Distributor의 역할, Exclusive/Sole의 실제 범위는 명칭만으로 확정하지 않는다. (S-03 195~211쪽)

## 6. 비즈니스 매너·클레임에서 익힌 내용

S-04는 소개 시 소속·직책·이름을 명료하게 전달하고, 명함의 이름·직함을 확인하며, 방문객 이동·좌석·식사에서 상대의 편의를 살피는 내용을 다룬다. 운전사가 있는 차량과 상대가 직접 운전하는 차량의 좌석 도식, 회의실·엘리베이터·식기 배치도 구별하여 읽었다. (S-04 3~27쪽)

성별·혼인 여부에 따른 소개·악수 순서, 악수 사양은 결례라는 문구, 음식 주문 방식 등은 해당 교재의 관습 설명이다. 모든 국가·상대에게 강제하지 않고 상대의 의사, 종교·문화, 건강·접근성, 현장 안내를 우선한다. 명함을 잊은 사람이나 악수를 원하지 않는 사람을 예절 위반으로 단정하지 않는다.

클레임은 다음 순서로 관리한다. (S-05 17~21쪽, S-03 212~217쪽)

1. 접수 사실과 유감을 신속히 알리고, 확인 담당·다음 회신기한을 정한다. 사실확인이 안 됐다는 이유로 무응답하지 않는다.
2. 거래ID·계약 버전·물품·로트·수량·발생일·장소·증상·사진·검사·물류자료·손해 산출을 확보한다.
3. 계약상 품질·검사·허용오차·책임 구간·통지기한·해결절차와 실제 사실을 대조한다.
4. 원인·영향과 재검사·수리·대체·반품·감액 등 처리안을 검토하고 권한 있는 당사자의 합의를 남긴다. 접수·유감 표명과 배상책임 확정은 구별한다.
5. 변경이슈에 담당·기한·금액·근거·종결기준을 연결하고 실제 수행·정산까지 확인한다. 다음 주문 가격과 자동 혼합하지 않는다.

## 9. 이후 업무에서 지킬 적용 원칙

1. 교육자료에서 배운 개념과 실제 확인값을 구별한다. 교재 예시의 통화·환율·단가·수량·결제·납기를 새 거래에 채워 넣지 않는다.
2. 자료를 근거로 설명할 때 자료ID와 PDF 쪽을 제시하고, 실제 실행 판단에는 거래 문서와 최신 공식 근거를 연결한다.
3. 가격 협상은 원가·자금·리스크·양보 조건까지 보고, 환리스크는 통화·금액·만기·확정 수준부터 측정한다.
4. 계약·상품·물류·서류·대금의 정보가 서로 맞는지 대조한다. 작성된 계획과 실제 완료를 구별한다.
5. 배운 내용은 기존 KDI 방식의 목적·실행·담당·근거·진행·증빙·변경·결과·정산 구조 안에서 사용한다.
