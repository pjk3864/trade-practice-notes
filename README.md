# 무역실무 학습노트

무역실무·환리스크 관리·수출마케팅·비즈니스 매너 교육자료 **5개, 총 765쪽**을 읽고 정리한 개인 학습 기록이다. 핵심 원리, 업무 적용 방법, 교재의 오류·재확인 사항과 원문 페이지를 연결한다.

기준일: **2026-11-11**

## 1. 읽는 순서

| 글 | 내용 |

| [통합 학습노트](docs/01_통합학습노트.md) | 계약·결제·물류·보험·통관·FTA, 환노출·헤지, 바이어 발굴·원가·협상·클레임과 실무 적용 |
| [주제별 원문 색인](docs/02_주제별_원문색인.md) | 교재 5개의 장별 PDF 페이지 안내 |
| [지식 저장소 등록 확인](docs/03_지식저장소_등록확인.md) | WeKnora·Tencent MemoryHub에 등록한 범위와 검증 결과 |

처음에는 통합 학습노트를 읽고, 필요한 주제를 색인에서 찾아 별도 보관한 원본 PDF와 대조한다. 계산·법규·상품조건의 재확인 항목은 통합 학습노트 8번에 모았다.

자료명은 학습 출처를 식별하기 위한 것이다. 원본 교재·로고·서명·이미지·OCR 전문의 재배포 허가를 뜻하지 않는다. 이 저장소에는 정리한 글만 보관한다.

## 3. 활용 기준

- 교육자료의 일반 개념과 특정 거래의 확정 조건을 구별한다.
- 품목·국가·수량·통화·환율·납기·결제조건은 실제 근거로 정한다.
- 계약·상품·물류·서류·대금의 정보가 맞는지 대조한다.
- 진행·완료는 실제 수행과 증빙으로 판단한다.
- 교재의 과거 법규·요율·금융상품 조건은 최신 공식 근거를 확인한 뒤 적용한다.

## 4. 보관 범위

원본 PDF, 페이지별 OCR 발췌문, 내부 확인 JSON, 계정·인증정보, 로컬 경로·시스템 식별자, 실제 거래자료와 업무 템플릿은 포함하지 않는다. 독립적인 학습 기록이며 특정 기관의 공식 교재·법률·세무·금융 자문을 대신하지 않는다.
